# Elementos gráficos

Do guia de marca: "design minimalista com uso estratégico de espaços em branco e elementos geométricos simples". SVGs no formato 1080×1350.

- **Arcos** (`arco-verde`, `arco-oliva`, `arco-bege`, `arco-linho`, `arco-marrom`, `arco-grafite`): três faixas concêntricas derivadas do arco do "m". Uma cor por peça; aplicar grande, sangrando pela borda, sobre fundo liso de outra cor da paleta. O `arco-oliva` tem um detalhe em `oliva-claro`.
- **Patterns** (`pattern-01` a `pattern-06`): colunas repetidas do ícone "bm" e das letras "b"/"m". 01 marrom + bege; 02 branco; 03 marrom + bege (só "b"); 04 bege + linho; 05 verde-profundo + bege (só "m"); 06 preto. Para embalagens, papel, fitas e fundos discretos; nunca atrás de texto pequeno.
