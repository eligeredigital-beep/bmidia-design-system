# Ícone "bm"

Monograma do guia de marca: "b" e "m" entrelaçados, com "DIGITAIS" espaçado embaixo (Montserrat, `grafite`). SVG recortado na área do ícone, fundo transparente.

| Arquivo | Cores | Fundo indicado |
|---|---|---|
| `bmidia-icone-verde.svg` | b `beige` + m `verde-profundo` | `cream`, `linho`, branco |
| `bmidia-icone-linho.svg` | b `linho` + m `beige` | `verde-profundo`, `grafite` (o "DIGITAIS" em grafite pede fundo claro: em fundo escuro prefira o `branco`) |
| `bmidia-icone-marrom-b.svg` | b `brown` + m `beige` | `cream`, `linho` |
| `bmidia-icone-marrom-m.svg` | b `beige` + m `brown` | `cream`, `linho` |
| `bmidia-icone-preto.svg` | `preto-marca` | positivo, impressão 1 cor |
| `bmidia-icone-branco.svg` | `branco-marca` | negativo: `olive`, `verde-profundo`, `brown`, fotos |
| `bmidia-icone-cinza-60.svg` / `-cinza-20.svg` | `cinza-60` / `cinza-20` | marca d'água, aplicações monocromáticas |

Use quando o espaço é quadrado ou pequeno (avatar, favicon, boné, crachá, selo). Respiro mínimo = altura do "b". Não separar o "b" do "m" nem trocar as cores fora destas versões.
